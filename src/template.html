Cube Solver

  1. Pegang kubus: putih di atas, hijau menghadap Anda.
  2. Pilih warna di palet, lalu ketuk stiker di kubus 3D. Geser untuk memutar tampilan.
  3. Angka di palet harus sama untuk semua warna (2×2: 4, 3×3: 9, 4×4: 16), lalu tekan Selesaikan.
  4. Ikuti langkahnya dengan ▶ atau ◀ / ▶▶. Notasi: R = kanan, L = kiri, U = atas, D = bawah, F = depan, B = belakang; ' = berlawanan jarum jam; 2 = 180°. Di 4×4, 2R = lapisan kedua dari kanan (bagian dalam), dst.
